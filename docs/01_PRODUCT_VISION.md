# CreatiBox 产品愿景 V0.1

## 1. 产品是什么

CreatiBox 是一个面向中小学生的单机网页创作工具。

它的目的不是教授一套固定编程知识，也不是让学生复刻老师给出的案例，而是让学生在一节约 40 分钟的课堂中，快速进入创作状态，并产出一个真正属于自己的数字作品。

## 2. 第一阶段使用场景

教师只需要给学生一个网页。

学生进入后可以：

- 选择创作类型
- 放置对象
- 修改对象外观
- 设置对象动作
- 设置对象之间的关系
- 测试作品
- 修改作品
- 保存作品

教师不需要：

- 创建账号
- 管理班级
- 监控学生屏幕
- 建立后台
- 收集操作日志

## 3. 产品核心思想

平台提前创造“能力”，学生创造“组合”。

学生不需要从零编写代码，而是在平台已经定义好的安全能力中进行：

- 选择
- 排列
- 组合
- 连接
- 修改
- 试验

真正的创作发生在“对象之间的新关系”中。

## 4. 世界观

CreatiBox 最终不是一组互不相关的小工具。

赛车、建筑、音乐、角色、动物、植物、故事、机关和关卡，最终都应该进入同一个可组合世界。

学生今天创造一辆赛车，明天创造一栋房子，后天创造一段音乐，再后来创造一个角色和故事，这些成果最终可以出现在同一个世界中。

## 5. 核心世界语言

```text
Entity → State → Action → Interaction → Transition
```

中文：

```text
实体 → 状态 → 动作 → 关系 → 状态变化
```

学生实际需要回答五个问题：

1. 这是什么？
2. 它现在是什么状态？
3. 它可以做什么？
4. 它可以和谁发生关系？
5. 发生关系以后会变成什么？

## 6. 第一版原则

第一版必须：

- 单机可用
- 浏览器直接运行
- 无账号
- 无服务器依赖
- 无公网 AI 依赖
- 无教师后台
- 无自由代码执行
- 允许本地保存与重新打开

## 7. 第一版验证目标

第一版只验证一个问题：

> 学生能否在没有教师逐步指导的情况下，用 CreatiBox 创建一个属于自己的可交互赛车场景。

如果这个闭环成立，再扩展音乐、建筑、故事等 Creator。
